# Add six mathematical Insight Expeditions and connect all eighteen lessons

The collection grows from twelve to eighteen lessons: staged SVD, Bayesian base
rates, Lagrange constrained extrema, sampling/aliasing, heat diffusion and
Fermat/Snell refraction. Each adds three guided presets, source links, a
coordinate contract, reference calculations and a worked investigation. For
example, a 7 Hz signal shares every 8 Hz sample with a signed −1 Hz alias, and a
heat profile loses fine detail while retaining its mean.

Catalog-driven conceptual connections now link all eighteen scenes, preserve
the reading tab and reveal destinations hidden by filters. Coordinate captions
also travel in sample/X3D metadata. Both new model modules enter source identity
checks, static Pyodide installation and the generated lesson-card schema. The
optional contact sheet projects the actual exported primitives and retains
source identities; it is not an X_ITE screenshot.

Validation includes 148 Python tests, three Node UI harnesses, three independent
mathematical probes, actual MCP calls for all eighteen scenes, and eighteen
X3D XSD/semantic validations. The new independent instrument checks 360 seeded
cases with Decimal/complex/NumPy/SciPy references and deliberate bad controls.
All default, extreme and preset sources stay inside export budgets.

Native browser rendering remains unverified on this restricted host. No Manim
video, GPU benchmark or learner-outcome study is claimed. The delivery provides
an incremental patch from Aha Atlas and a cumulative patch from upstream
24c9bbd; it does not push or deploy changes.
