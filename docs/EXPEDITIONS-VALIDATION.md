# Insight Expeditions verification

This edition contains eighteen lessons and fifty presets. Earlier receipts
describe their named editions; current automated evidence is regenerated from
the present source and records hashes and runtime versions.

| Instrument | Evidence and scope |
|---|---|
| Python suite | 148 tests, including 27 new model tests, preset/card recovery, geometry budgets, static import closure, HTTP calls for all defaults, and prior renderer controls |
| Three Node harnesses | Request/scene ordering; learning tools; coordinate captions and valid connections with filter and keyboard-focus behavior |

| Actual MCP stdio | Tool registration, eighteen-lesson inventory and scene calls, identity checks and refusal control |
| Pinned x3d_mcp | All eighteen default exports pass X3D 4.0 XSD and semantic diagnostics; paired invalid controls are exercised |
| Manim source | Default and additional preset/extreme sources compile; actual Manim video rendering was not performed |
| Contact sheet | Actual model primitives rendered through a declared orthographic projection using optional Matplotlib; geometry and projection utility checks pass |

Run `python3 tools/check_release.py`. The new instrument can be run separately
with `python3 tools/probe_expeditions.py`; missing optional scientific packages
produce `not_run` checks and overall `partial`, never a successful mathematical
comparison. Release validation requires each declared independent receipt to
report `pass`.

`python3 tools/render_expedition_preview.py` reproduces the contact sheet.
Matplotlib is optional and is not imported by the interactive application or
installed in Pyodide. Model source hashes are embedded in the PNG metadata.

## Native browser boundary

The earlier edition established that this host blocks the installed browser's
required socket operations and that the separate cloud browser cannot reach
the local server. Native X_ITE/Pyodide rendering remains unverified here. The
contact sheet is explicitly a geometry projection, not a browser screenshot.
No new GPU benchmark, mobile-layout result, Manim video or learner-outcome
measurement is claimed. Static module dependency and standard-library tests
cover both new lesson modules.

On a browser-capable host, run the local app and
`node tools/browser_smoke.js http://127.0.0.1:8850/`. The tool now expects eighteen
scenes. Exercise the static `/web/` version separately; also check coordinate
captions, all conceptual connections, presets, animations, atlas access and a
narrow viewport before publishing.

a cumulative patch from upstream commit

of their declared baselines. GitHub and Pages are not modified by this work.
